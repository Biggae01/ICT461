# ICT461 Course Registration Portal

Task 1 deliverable: an accessible registration interface (`index.html`,
`styles.css`, `app.js`, `api.js`) that talks to the Express API on
`http://localhost:3000`.

## Run it
1. Start the Express API on port 3000.
2. Serve this folder on port 5500 (e.g. VS Code Live Server).
3. Open `index.html`.

See commit history for the build order and DevTools notes below.
